# Zenrock Plugin for ElizaOS

This repository contains the Zenrock plugin for ElizaOS. Zenrock is a Cosmos dMPC chain that provides secure multi-party computation within the ElizaOS environment. The plugin integrates with ElizaOS to facilitate secure workspace policies, request keys, and signatures.

## Features
- Secure multi-party computation (dMPC) integration
- Workspace policy management
- Request key generation and signature handling
- Seamless integration with ElizaOS

## Prerequisites
- Node.js (version 23+ recommended)
- pnpm or yarn package manager
- ElizaOS installed and configured ([ElizaOS Documentation](https://eliza.gg/eliza/docs/intro/))
